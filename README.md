# KisaanYuva – AI-Powered Application for the farmers

**KisaanYuva** is a powerful, user-friendly mobile application that helps you identify plant diseases using the latest AI advancements. Simply upload or capture an image of your plant, and let PlantIQ analyze it using Google's Gemini API. The app also offers multilingual support, real-time agricultural news, and a built-in chatbot for guidance and support.

---

##  Key Features

###  Plant Disease Detection (Powered by Gemini API)
Capture or upload a photo of your plant, and PlantIQ will:
- Analyze the image using Gemini's AI capabilities
- Identify possible diseases
- Provide prevention tips or remedies

Ideal for farmers, gardeners, and students in the agricultural domain.

###  Capture or Upload Images
- Use your device’s camera to **click a live photo**  
- Or **upload an image** from the gallery for analysis

###  Multi-language Support
PlantIQ breaks language barriers by providing:
- Disease names
- Solutions and insights
- UI prompts  
...in multiple regional languages, ensuring accessibility for all.

###  Agricultural News Section
Stay informed with a dedicated **news section** covering:
- Latest trends in agriculture
- Government schemes
- Disease outbreaks and weather alerts

###  Built-in Chatbot
Got questions? Ask away!
- The AI-powered chatbot is available for guidance
- Available in multiple languages
- Can help with disease information, usage guidance, or general queries

##  Tech Stack

| Tool | Purpose |
|------|---------|
| **Flutter & Dart** | Cross-platform frontend framework |
| **Gemini API (by Google)** | Used for image analysis and chatbot features |
| **ML Models (via Gemini Vision APIs)** | Image-to-text conversion and classification |
| **HTTP/Dio** | API requests and file uploads |
| **Flutter Localizations** | Internationalization and localization support |
